Write the single line you would send your younger self if one line were all you got. Free to enter, judged blind, and the best line takes the whole $2.

The entry line (153 characters, one sentence, one line):

> The friend you lose over a borrowed bike is the one you'll still look for in every crowd at forty — ride back now, kid, and return it before summer ends.

The line is built on one specific, lived incident — a friendship lost over a borrowed bike — instead of a motto anyone could wear. The older self knows two things the younger one cannot: that this friend is the one he will still look for in every crowd at forty, and that the bike can still be returned before summer ends. The turn lands late, the sting is the smallness of what was lost, and the imperative ("ride back now, kid") is addressed to the younger self directly.

## Run it

```sh
python3 main.py
```

By default it writes `entry.txt` to `/output` (the harness path); set `MAKEFUN_OUTPUT_DIR` to write somewhere else. The file holds the line exactly, with no trailing newline.
